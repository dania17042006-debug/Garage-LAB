# Garage: власний сайт з акаунтами (для вас і друзів)

Що вийде: сайт за вашою адресою. Кожен друг реєструється своєю поштою й веде **свої** дані, які не змішуються з вашими. Дані лежать у базі й не зникають при закритті застосунку. Працює без Claude.

Потрібно: ~40 хвилин, пошта, 2 безкоштовні акаунти (Supabase і GitHub). Нічого платного.

---

## Частина 1. База даних (Supabase), ~10 хв

1. Відкрийте **supabase.com** → **Start your project** → увійдіть (через GitHub або пошту).
2. **New project**:
   - Name: `garage`
   - Database Password: вигадайте й **збережіть** (потім не знадобиться, але не губіть)
   - Region: **Frankfurt (eu-central-1)**, це найближче до Польщі
   - Plan: Free → **Create new project**. Зачекайте 1–2 хвилини.
3. Зліва відкрийте **SQL Editor** → **New query**. Відкрийте файл **supabase-setup.sql**, скопіюйте ВЕСЬ текст, вставте й натисніть **Run**. Має з'явитись «Success».
4. Зліва **Authentication** → знайдіть налаштування **Email** (розділ Providers / Sign In) → **вимкніть «Confirm email»** → Save.
   (Інакше кожному другові треба підтверджувати пошту листом, а безкоштовна пошта Supabase пропускає лише кілька листів на годину.)
5. Зліва внизу **Project Settings** → **API** (або «API Keys»). Скопіюйте два значення:
   - **Project URL** (виглядає як `https://abcdefgh.supabase.co`)
   - **anon / public key** (довгий ключ; у новому інтерфейсі може називатись «publishable key»)

   Ці значення **публічні** за задумом, їх можна надіслати мені в чат: я підставлю їх у **config.js** і дам готовий файл.

## Частина 2. Сайт (GitHub Pages), ~15 хв

1. Відкрийте **github.com** → зареєструйтесь → **New repository**: назва `garage`, **Public**, **Create repository**.
2. На сторінці репозиторію натисніть **uploading an existing file** і завантажте **усі** файли з папки garage-site (крім цієї інструкції і SQL):
   `index.html`, `config.js` (з вписаними значеннями), `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`
   → внизу **Commit changes**.
3. **Settings** (вкладка репозиторію) → **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
4. Через 1–2 хвилини вгорі сторінки Pages з'явиться адреса: `https://ВАШ-НІК.github.io/garage/`. Це і є ваш сайт.
5. Поверніться в Supabase → **Authentication** → **URL Configuration**: у **Site URL** вставте цю адресу й додайте її в **Redirect URLs** → Save.
   (Потрібно для відновлення пароля через пошту.)

## Частина 3. Перевірка

1. Відкрийте адресу сайту на iPhone в **Safari** → **Створити акаунт** (пошта + пароль від 6 символів).
2. Додайте деталь і фото. Закрийте й відкрийте знову: усе на місці.
3. **Поділитися → На екран «Домівка»**: іконка з'явиться на головному екрані.
4. Налаштування (шестірня) → блок **Акаунт**: ваша пошта, «Вийти», відгук, видалення акаунта. Нижче **Резервна копія**.

## Перенесення ваших теперішніх даних зі старої версії (у Claude)

1. У старій версії: Налаштування → **Резервна копія → Зберегти файл** (збережеться .json).
2. У новому сайті після реєстрації: Налаштування → **Відновити з файлу** → оберіть цей .json → «Замінити дані».
Фото й усі дані перенесуться.

## Друзям

- Надішліть адресу сайту. Кожен реєструється сам, дані окремі.
- Відгуки, які вони пишуть у застосунку, ви читаєте в Supabase: **Table Editor → feedback**.
- Щоб ніхто сторонній не міг реєструватись, коли друзі вже зареєстровані: Supabase → **Authentication** → вимкніть **Allow new users to sign up**.

## Оновлення застосунку
Я даю новий `index.html`. На GitHub відкрийте старий файл → олівець/Upload → замініть → Commit. Друзі просто оновлюють сторінку.

## Важливо знати (чесно)
- **Безкоштовний Supabase «засинає»**, якщо тиждень ніхто не користувався. Тоді в Supabase натисніть **Restore project**; дані зберігаються.
- Як власник проєкту ви **технічно маєте доступ** до всіх даних у панелі Supabase. Друзі користуються правилами бази, а ви адміністратор. Домовтесь із ними, що не переглядаєте їхні дані. Кожен може сам видалити свої дані в Налаштуваннях.
- Репозиторій публічний (так працює безкоштовний GitHub Pages): код видно всім, а дані друзів ні.
- Безкоштовні ліміти: 500 МБ бази й 1 ГБ фото, для кількох друзів досить.
